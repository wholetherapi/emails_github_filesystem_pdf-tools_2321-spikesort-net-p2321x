# SpikeSort-Net

Official implementation of **SpikeSort-Net: Contrastive Spike Sorting for
High-Density Neural Arrays** (NeurIPS 2024).

**Release status: public release.** The full training pipeline used for the
NeurIPS 2024 results is included in this repository.

## Contents

- `src/` - contrastive encoder, clustering head and training loop
- `configs/` - experiment configuration for the dense-array benchmarks
- `experiments/` - scripts reproducing the benchmark tables
- `data/` - spike-array preprocessing notes
